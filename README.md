## 📖 SOBRE A LOJA

A **StarWord** é uma loja online de jogos intelectuais, criada para quem acredita que diversão e raciocínio andam juntos. 💡

Aqui, cada jogo é uma chance de pensar diferente, criar estratégias, testar o conhecimento e passar um tempo de qualidade com quem importa, seja em família, entre amigos ou sozinho.

---

## 💫 POR QUE STARWORD?

| ✨ Diferencial | 📄 O que significa |
|---|---|
| 🧠 **Jogos que fazem pensar** | Todo o catálogo é escolhido por estimular lógica, estratégia, memória e criatividade |
| 👥 **Feitos para jogar junto** | Opções para duplas, grupos, festas e noites em família |
| 🎯 **Para todos os níveis** | Do primeiro jogo ao desafio mais difícil, tem algo para cada jogador |
