# StarWord (PHP + MVC, sem JavaScript)
1. Importe o SQL (tabelas_site.pdf) em um banco chamado `starword` e cadastre categorias: "Tabuleiro", "Cartas", "Quizzes".
2. Ajuste usuário/senha em `app/config.php`.
3. Rode: `php -S localhost:8000 -t public` e acesse http://localhost:8000
4. Para virar ADM: insira o id do usuário na tabela Administradores.
Imagens: procure os textos "colocar imagem" nas views.
